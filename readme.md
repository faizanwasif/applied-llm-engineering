# LLM and Agent Engineering Mastery

A comprehensive curriculum and resource repository covering the end-to-end development of Large Language Models (LLMs) and autonomous agentic systems. This repository transitions from core theoretical fundamentals to advanced production-grade agent architectures.

## LLM Fundamentals
- Transformer Mechanics: Tokenization, context windows, and generation controls (temperature, top-p, penalties).
- Model Families: Open weights vs. closed models, pricing, and token economics.
- Core Concepts: Reasoning vs. standard models, fine-tuning, embeddings, and RAG basics.

## Prompt Engineering
- Fundamentals: Core principles, specificity, and contextual design.
- Best Practices: Iteration, testing, and length/format specification.
- Reasoning Patterns: Chain of Thought (CoT) and Tree of Thought (ToT).

## AI Agents 101
- Agent Loop: Perception, reasoning, planning, acting, and reflection.
- Practical Applications: Personal assistants, data analysis, web scraping, and NPC design.

## Tools and Actions
- Tool Design: Schema definition, input/output handling, and error management.
- Integrations: Web search, REPL, database queries, and API access.
- Model Context Protocol (MCP): Architecture, implementation, and deployment (local vs. remote).

## Agent Memory
- Types: Short-term (contextual) vs. long-term (vector/SQL).
- Classification: Episodic vs. Semantic memory.
- Maintenance: Summarization, compression, and forgetting strategies.

## Building Agents
- Development Approaches: Manual implementation vs. native function calling.
- Architectures: ReAct, RAG Agents, Planner-Executor, DAGs, and Multi-Agent systems.
- Frameworks: LangChain, LangGraph, LlamaIndex, Haystack, CrewAI, AutoGen, and Smolagents.

## Evaluation and Testing
- Quality Assurance: Unit testing for tools and integration testing for agentic flows.
- Observability: Telemetry, structured logging, and tracing.
- Tooling: LangSmith, DeepEval, Ragas, and Helicone.

## Security and Ethics
- Guardrails: Prompt injection protection and jailbreak prevention.
- Compliance: Access control, tool sandboxing, and PII redaction.
- Alignment: Bias mitigation, toxicity guardrails, and red teaming.
